Rate limits are enforced by the gateway before the model is called. Add a limit on ab_split (e.g. 5 requests / minute), wait ~2 min for it to propagate, then fire a burst: the extra requests come back as HTTP 429 (rate limited). A limit of 0 blocks everything (HTTP 403). “model QPS cap” is a different 429: Free Edition's own per-model limit, not yours.
